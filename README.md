# 🎬 Ingressos para o Cinema

Projeto desenvolvido em Java para praticar conceitos de Programação Orientada a Objetos (POO).

## Funcionalidades

- **Ingresso:** armazena o valor, o nome do filme e o idioma.
- **MeiaEntrada:** aplica 50% de desconto no valor do ingresso.
- **IngressoFamilia:** calcula o valor total de acordo com a quantidade de pessoas e aplica 5% de desconto para grupos com mais de 3 pessoas.

## Conceitos praticados

- Herança
- Encapsulamento
- Polimorfismo
- Sobrescrita de métodos (`@Override`)
- Construtores (`super()`)

## Tecnologias

- Java

## Como executar

Execute a classe `Main` em uma IDE compatível com Java.
